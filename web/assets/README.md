# Household Brain identity

The home-and-context symbol and wordmark were created for this project. The app uses the original media identity, with no third-party photography, private household data or external asset requests.

The wordmark contains outlined Bricolage Grotesque Bold letterforms. Bricolage Grotesque is licensed under the SIL Open Font License 1.1; the unmodified license is in `BricolageGrotesque-OFL.txt`. No font software is embedded or downloaded. The app body uses system fonts.

The logo does not indicate connected devices, household accounts or native Alexa support. Only the two explicitly named SVG files are served by the local demo; this documentation and font license remain available in the source package.

The two measured-recipe food SVGs are original media artwork created for this project: herb chicken with Brussels sprouts/quinoa, and a steak fajita cauliflower-rice bowl. They are decorative illustrations, not photographs, observed portions or completed-app evidence. They contain no external images, scripts or remote references. Their exact local GET paths are allowlisted; no directory serving is enabled.
