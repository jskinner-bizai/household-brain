What this prototype does

No purchases, devices, Alexa, speech recognition, LLM or AWS service is connected. The server has no authentication or persistence. Changes are shared within this running server; refreshing the page does not reset them. Browser requests use exact Host/Origin checks. Preview tokens protect against changed state; they are not authentication.

How additions are checked

The server adds one unit per missing item, not recipe-serving quantities. A name in another unit stays separate and is shown before confirmation. Every add validates the preview and current household state together, atomically. If relevant state changed, nothing is added: review the updated preview and confirm again.
