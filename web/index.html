About this sample

The grocery list changes in this running server only. Changes reset when the server restarts, not when you refresh this page. No devices, Alexa, speech recognition, LLM or AWS service is connected. The server has no authentication or persistence. Browser requests use exact Host/Origin checks. Preview tokens protect against changed state; they are not authentication.

How the check works

The server adds one unit per missing item, not recipe-serving quantities. A name in another unit stays separate and is shown before confirmation. Every add validates the preview and current household state together, atomically. If relevant state changed, nothing is added: review the updated preview and confirm again.
